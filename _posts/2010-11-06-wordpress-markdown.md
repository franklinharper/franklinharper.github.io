[Markdown](http://daringfireball.net/projects/markdown/basics) is a wonderful simple and lightweight markup language. The basic idea is that it looks just like normal text. I actually find Markdown's relative non WYSIWIGness to be an advantage because it allows concentrating more on communicating ideas than getting distracted by too many visual bells and whistles.\r\n\r\nThanks to [Michel Fortin](http://michelf.com/contact/)'s excellent [PHP Markdown](http://michelf.com/projects/php-markdown/) Wordpress plugin you can use Markdown for posts in your Wordpress blog.\r\n\r\nIf you're sick of using WYSIWIG editors, then I'm sure it's worth trying [Markdown](http://daringfireball.net/projects/markdown/basics).
